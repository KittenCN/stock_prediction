# 安全问题报告 | Security reporting

项目目前没有正式 GitHub Release，也没有承诺支持的版本分支。维护以 `master` 分支为准；历史代码和模型文件不保证安全更新。

请优先使用本仓库 **Security → Report a vulnerability** 私下提交漏洞报告（如果 GitHub 提供此选项）。如该入口不可用，请通过仓库所有者的 GitHub 主页联系维护者，先约定私下传递详情的方式。不要在公开 Issue 中提交可利用的漏洞细节、凭据或个人数据。

报告中请写明受影响的提交、复现条件、潜在影响和最小复现步骤。维护者会先确认问题，再讨论修复和披露时机；当前没有固定响应时间承诺。

---

There is no formal GitHub release or supported version branch yet. Maintenance targets `master`; historical code and model files are not guaranteed security updates. Use the repository's private vulnerability reporting option if available. Otherwise contact the maintainer through their GitHub profile to arrange a private channel before sending details. Please do not disclose exploits, credentials, or personal data in a public issue.
